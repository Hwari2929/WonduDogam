## 이 문서를 믿어도 되는 범위

두 문서는 **구현된 것**을 적습니다. 값의 출처는 코드이고, 둘이 어긋나면 코드가
맞습니다. `tests/rendered-html.test.mjs` 의 47개 검사가 문서에 적힌 약속(자간,
아이콘 굵기, 단계가 갈리는 배율, 시트가 넘어가는 값 …) 중 지켜져야 하는 것들을
소스에 대고 확인합니다.

## 처음 기획과의 관계

원래의 기획 문서(01 서비스 정의 · 02 디자인 시스템 v0.1 · 03 기능 명세 · 결정서)는
이 저장소에 들어온 적이 없습니다 — 코드 주석이 절 번호로 참조만 하고 있었습니다.
그래서 이 둘은 **다시 쓴 것**이지 고쳐 쓴 것이 아닙니다. 절 번호와 짜임은 주석이
가리키던 것을 그대로 따랐습니다.

만들면서 기획과 달라진 자리는 지우지 않고 각 절 끝 **"바뀐 것"** 에 이유와 함께
남겼습니다. 큰 것만 추리면:

- **카카오맵 SDK 를 걷어냄** — 붙여 보니 카카오맵과 다를 게 없었습니다. 지도는
  공공 데이터로 직접 그립니다.
- **경계 단계에서 시도를 뺌** — 확대하는 동안 경계가 두 번 바뀌어 어지러웠습니다.
- **첫 화면에서 영수증 프린트 연출을 뺌** — 아직 아무것도 고르지 않은 사람 앞에
  종이가 지도를 덮고 서 있었습니다.
- **시트의 손잡이 바를 걷어내고 이름 띠로 바꿈** — 손잡이 하나로는 무엇을 잡으면
  무엇이 되는지 전해지지 않았습니다.
- **검색을 기입란 한 줄로** — 같은 말을 세 번 하고 있었습니다.
- **아이콘을 lucide 한 벌 · 1.5px 한 굵기로** — 굵기가 여섯 가지였습니다.
- **손짓이 이어지는 동안 지도를 다시 그리지 않음** — 오므리는 동안의 래스터가
  1,233ms 였습니다.

01(서비스 정의)과 결정서는 만들면서 바뀐 것이 없어 다시 쓰지 않았습니다. 원본을
주시면 이 둘과 나란히 두겠습니다.
